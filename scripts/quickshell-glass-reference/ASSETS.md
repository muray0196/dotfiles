# Reference scene assets

- `reference.png`: user-supplied Apple Liquid Glass reference screenshot from
  this conversation, 1531 × 611 pixels. Related official presentation:
  [Meet Liquid Glass, WWDC25](https://developer.apple.com/videos/play/wwdc2025/219/).
  The exact screenshot timestamp is not established. Retained for local comparison.
- `flower.png`: AI-generated reconstruction made on 2026-10-17 from that
  screenshot, removing all three glass controls and playback symbols. The
  covered background was inferred; this is not Apple's original photograph.
  The scene stretches it to the reference's stage dimensions without adjusting
  colour, exposure, or contrast.

The glass and playback icons shown in the live scene are rendered separately.
No reference glass, highlight, distortion, or icon is baked into `flower.png`.
