## Meta

* Language: Always use English, regardless of input language.

## Constraints

* Prefer existing dependencies and standard-library solutions. Add a dependency only when it is required for the requested change.
* Keep changes narrowly scoped to the request. Make only the requested changes and supporting changes strictly required for correctness.
* Prefer evidence from the repository over assumptions.
* Keep unnecessary information out of your context. Start with the smallest sufficient amount of information, expanding scope or detail as needed. Filter or summarize large outputs before they enter context. Design tools and workflows you create to return minimal useful agent-facing output by default, with further detail available on demand. Preserve relevant errors and evidence, and do not reduce required validation.
